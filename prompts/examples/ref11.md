# 예시: 11번 레퍼런스 + 3D 전환 + 워드마크

결과물: [`examples/ref11-intro.mp4`](../../examples/ref11-intro.mp4) · 코드: [`src/examples/ref11/Ref11Intro.tsx`](../../src/examples/ref11/Ref11Intro.tsx)

## 레퍼런스 분해 (Reference_Video_11, 앞 4초)

상태바 아이콘이 로딩 심볼로 바뀌는 모션을 After Effects로 따라 만든 "Copy Study"입니다.

| 시간 | 일어나는 일 |
|---|---|
| 0.0–0.6s | 정지: 신호 막대 4개 · 와이파이 · 배터리 |
| 0.6–1.1s | 막대 4개 → 점 4개로 세로 압축 / 배터리 → 알약 → 세로 막대 |
| 1.1–1.2s | 한 박자 정지 |
| 1.2–2.3s | 세로 막대가 휘어 원호가 되고, 와이파이 주위를 돌며 길어짐 |
| 1.7–2.6s | 점 4개가 곡선 경로로 줄지어 원호의 빈틈으로 이동 |
| 2.6–2.9s | 살짝 튕기며 안착 → 원 + 와이파이 + 점 |

- **핵심 원리:** 새 요소 없이, 기존 요소가 모양을 바꾸고 경로를 따라 이동해 새 심볼로 재조립
- **이징:** 매우 강한 in-out, 안착할 때만 살짝 튕김

## 의도 카드

```text
1. 한 문장 의도: 흩어진 기본 요소(점·선·원)가 모여 하나의 생각(마크)이 되고,
   그 생각이 입체로 깨어나며 이름(워드마크)을 얻는다.
2. 가져올 것: 기존 요소가 모양을 바꾸고 경로를 따라 이동해 새 심볼로 재조립되는 원리
   버릴 것: 상태바라는 소재, 빨간 강조색
3. 내가 더할 것: 2D 조립이 끝나면 3D로 전환되어 홈페이지처럼 회전하고,
   마크가 왼쪽으로 비켜서며 오른쪽에 워드마크가 등장한다.
4. 왜 Phi다운가: "Fundamentals Over Tools" — 2D = 기본기, 3D = 그 위에서 확장되는 사고
5. 마지막 장면: 왼쪽에 3D 마크가 한 바퀴 돌고 마크 자세로 멈춤, 오른쪽에 워드마크 3줄.
   시작 화면과 같은 로크업 구도로 끝난다.
```

## 매핑

| 레퍼런스 | Phi 소스 |
|---|---|
| 와이파이 (중심, 유지) | `ring-a` |
| 배터리 → 막대 → 원호 | 워드마크 `I` → 휘어 궤도를 돌며 `ring-b` |
| 신호 막대 → 점 | 워드마크 각 줄 → `i1-dot`, `i2-dot`, `i3-dot` |
| 점이 빈틈에 안착 | 점 3개가 `ring-b` 빈틈에 안착 후 선으로 녹아듦 |

## 구성 (8초, 240프레임)

| 막 | 프레임 | 내용 |
|---|---|---|
| 1. 2D 분해·조립 | 0–18 | 정지: 왼쪽 `ring-a`, 오른쪽 워드마크 |
| | 18–33 | 글자가 각 줄의 i 점으로 눌려 모임, `I`만 막대로 남음 |
| | 36–72 | `I`가 휘어 원호가 되고 `ring-b` 궤도를 돌며 길어짐, `ring-a`는 중앙으로 |
| | 51–78 | 점 3개가 곡선을 타고 줄지어 빈틈에 안착 (spring) |
| | 84–92 | 빈틈이 닫히며 점이 선에 녹아듦 → 2D 마크 |
| 다리 | 90–106 | 2D 링을 `HERO_MARK_POSE`로 보간 → 4프레임 크로스페이드로 3D 교체 |
| 2. 3D 깨어남 | 102– | `startAt="mark"`, `speed=1.5`로 정지 상태에서 가속하며 회전 |
| | 132–170 | 3D 마크가 왼쪽 로크업 자리로, 점이 먼저 나타나고 글자가 거기서 다시 자람 |
| 끝 | 214–240 | 3D가 한 바퀴를 마치고 마크 자세로 정지, 최종 로크업 |

이징: 1막 `cubic-bezier(0.83, 0, 0.17, 1)` (11번의 강한 가속·감속), 2막 `cubic-bezier(0.35, 0, 0, 1)` (Phi 인트로 이징)

**의도에서 나온 결정:** 흩어졌던 i의 점이 마지막에 워드마크로 돌아오는 수미상관. 레퍼런스에는 없는 장치입니다.
