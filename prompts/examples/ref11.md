# 예시: 11번 레퍼런스 + 3D 전환 + 워드마크

결과물: [`examples/ref11-intro.mp4`](../../examples/ref11-intro.mp4) · 코드: [`src/examples/ref11/Ref11Intro.tsx`](../../src/examples/ref11/Ref11Intro.tsx)

## 레퍼런스 분해 (Reference_Video_11, 앞 4초)

상태바 아이콘이 로딩 심볼로 바뀌는 모션을 After Effects로 따라 만든 "Copy Study"입니다.

| 시간 | 일어나는 일 |
|---|---|
| 0.0–0.6s | 정지: 신호 막대 4개 · 와이파이 · 배터리 |
| 0.6–1.1s | 막대 4개 → 점 4개로 세로 압축 / 배터리 → 알약 → 세로 막대 |
| 1.1–1.2s | 한 박자 정지 |
| 1.2–2.3s | 세로 막대가 휘어 원호가 되고, 와이파이 주위를 돌며 길어짐 |
| 1.7–2.6s | 점 4개가 곡선 경로로 줄지어 원호의 빈틈으로 이동 |
| 2.6–2.9s | 살짝 튕기며 안착 → 원 + 와이파이 + 점 |

- **핵심 원리:** 새 요소 없이, 기존 요소가 모양을 바꾸고 경로를 따라 이동해 새 심볼로 재조립
- **이징:** 매우 강한 in-out, 안착할 때만 살짝 튕김

## 의도 카드

```text
1. 한 문장 의도: 점 하나(가장 작은 기본 요소)가 선이 되고, 선이 궤도를 그리며 하나의 생각(마크)이 되고,
   그 생각이 입체로 깨어나며 이름(워드마크)을 얻는다.
2. 가져올 것: 막대가 휘어 궤도를 돌며 길어지고, 점들이 줄지어 빈틈에 안착하는 원리
   버릴 것: 상태바라는 소재, 빨간 강조색
3. 내가 더할 것: 2D 마크가 완성되면 3D로 전환되어 홈페이지처럼 회전하고,
   마크가 왼쪽으로 비켜서며 오른쪽에 워드마크가 등장한다.
4. 왜 Phi다운가: "Fundamentals Over Tools" — 점·선·원(기본기)으로 2D를 세우고, 3D(확장)로 나아간다
5. 마지막 장면: 왼쪽에 3D 마크가 한 바퀴 돌고 마크 자세로 멈춤, 오른쪽에 워드마크 3줄.
   시작은 빈 화면의 점 하나, 끝은 로크업.
```

## 매핑

| 레퍼런스 | Phi 소스 |
|---|---|
| 배터리 → 세로 막대 | 점 하나 → 길어져 세로 선 |
| 막대 → 원호가 궤도를 돌며 길어짐 | 두 링이 만나는 자리에서 선이 X로 갈라져, 위쪽은 `ring-a`, 아래쪽은 `ring-b` 궤도를 반대 방향으로 돎 |
| 신호 막대 → 점 4개 | 선이 길어질 때 아래 끝에서 점 3개가 떨어져 나와 매달림 |
| 점이 줄지어 빈틈에 안착 | 점 3개가 마크 아래로 휘어 `ring-a`의 SW 끝 빈틈에 안착 → 선으로 녹아듦 |

## 구성 (8초, 240프레임)

| 막 | 프레임 | 내용 |
|---|---|---|
| 1. 점 → 선 → 2D 마크 | 0–16 | 빈 화면 중앙에 점 하나가 톡 나타남 |
| | 16–30 | 점이 길어져 세로 선이 되며 두 링이 만나는 자리로 이동, 아래 끝에서 점 3개가 떨어져 매달림 |
| | 38–78 | 선이 X로 갈라져 두 링 궤도를 반대 방향으로 돌며 길어짐 (`ring-b`는 닫히고 `ring-a`는 SW 끝에 빈틈) |
| | 56–83 | 점 3개가 마크 아래로 휘어 줄지어 빈틈에 안착 (spring) |
| | 86–94 | 빈틈이 닫히며 점이 선에 녹아듦 → 2D 마크 |
| 다리 | 94–110 | 2D 링을 `HERO_MARK_POSE`로 보간 → 4프레임 크로스페이드로 3D 교체 |
| 2. 3D 깨어남 + 이름 | 106– | `startAt="mark"`, `speed=1.5`로 정지 상태에서 가속하며 회전 |
| | 134–168 | 3D 마크가 왼쪽 로크업 자리로, 오른쪽에 줄마다 점이 먼저 나타나고 그 점에서 글자가 자람 |
| 끝 | 218–240 | 3D가 한 바퀴를 마치고 마크 자세로 정지, 최종 로크업 |

이징: 1막 `cubic-bezier(0.83, 0, 0.17, 1)` (11번의 강한 가속·감속), 2막 `cubic-bezier(0.35, 0, 0, 1)` (Phi 인트로 이징)

## 의도에서 나온 결정
- **점 하나에서 시작합니다.** 가장 작은 기본 요소에서 출발해 "기본기"를 보여 줍니다.
- **워드마크도 점(i의 점)에서 자라게 했습니다.** 마크와 이름이 같은 씨앗에서 나온다는 수미상관으로, 레퍼런스에는 없는 장치입니다.
