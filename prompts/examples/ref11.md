# 예시: 11번 레퍼런스 + 3D 전환 + 워드마크

결과물: [`examples/ref11-intro.mp4`](../../examples/ref11-intro.mp4) · 코드: [`src/examples/ref11/Ref11Intro.tsx`](../../src/examples/ref11/Ref11Intro.tsx)

**최종본(카메라 포함):** 컴포지션 `Ref11IntroCamera`. 같은 장면에 카메라 두 가지를 더했습니다. 점에 5배로 붙어 시작해 빠지기, 마크를 크게 보다가 빠지며 오른쪽으로 패닝해 이름 드러내기.

## 레퍼런스 분해 (Reference_Video_11, 앞 4초)

상태바 아이콘이 로딩 심볼로 바뀌는 모션을 After Effects로 따라 만든 "Copy Study"입니다.

| 시간 | 일어나는 일 |
|---|---|
| 0.0–0.6s | 정지: 신호 막대 4개 · 와이파이 · 배터리 |
| 0.6–1.1s | 막대 4개 → 점 4개로 세로 압축 / 배터리 → 알약 → 세로 막대 |
| 1.1–1.2s | 한 박자 정지 |
| 1.2–2.3s | 세로 막대가 휘어 원호가 되고, 와이파이 주위를 돌며 길어짐 |
| 1.7–2.6s | 점 4개가 곡선 경로로 줄지어 원호의 빈틈으로 이동 |
| 2.6–2.9s | 살짝 튕기며 안착 → 원 + 와이파이 + 점 |

- **핵심 원리:** 새 요소 없이, 기존 요소가 모양을 바꾸고 경로를 따라 이동해 새 심볼로 재조립
- **이징:** 매우 강한 in-out, 안착할 때만 살짝 튕김

## 의도 카드

```text
1. 한 문장 의도: 점 하나(가장 작은 기본 요소)가 선이 되고, 선이 타원이 되고, 타원이 돌며 둘로 나뉘어
   하나의 생각(마크)이 된다. 그 생각이 입체로 깨어나며 이름(워드마크)을 얻는다.
2. 가져올 것: 한 요소가 모양을 바꾸며 다음 형태로 이어지는 원리 (배터리 → 막대 → 원호), 강한 가속·감속
   버릴 것: 상태바라는 소재, 빨간 강조색, 여러 요소가 따로 움직이는 복잡함 (점 여러 개)
3. 내가 더할 것: 2D 마크가 완성되면 3D로 전환되어 홈페이지처럼 회전하고,
   마크가 왼쪽으로 비켜서며 오른쪽에 워드마크가 한 번에 올라온다.
4. 왜 Phi다운가: "Fundamentals Over Tools" — 점·선·원(기본기)으로 2D를 세우고, 3D(확장)로 나아간다
5. 마지막 장면: 왼쪽에 3D 마크가 한 바퀴 돌고 마크 자세로 멈춤, 오른쪽에 워드마크 3줄.
   시작은 빈 화면의 점 하나, 끝은 로크업.
```

## 매핑

| 레퍼런스 | Phi 소스 |
|---|---|
| 배터리 → 알약 → 세로 막대 | 점 하나 → 세로로 길어져 선 |
| 막대 → 휘어 원호 | 선 → 옆으로 벌어져 타원 |
| 원호가 궤도를 돌며 완성 | 타원이 시계방향으로 돌며 두 개로 나뉨 → `ring-a`(225°), `ring-b`(135°) |

모든 도형은 `<ellipse>` 하나로 표현합니다. 점은 rx·ry가 0에 가까운 타원, 선은 rx만 0에 가까운 타원입니다. 그래서 점 → 선 → 타원 → 두 링이 끊김 없이 이어집니다. 다만 아주 납작한 타원은 끝이 각져 보여서, 점·선 구간만 둥근 끝 `<line>`으로 그리고 타원이 벌어지기 시작할 때 넘깁니다.

## 구성 (8초, 240프레임)

| 막 | 프레임 | 내용 |
|---|---|---|
| 1. 점 → 2D 마크 | 0–14 | 빈 화면 중앙에 점 하나가 톡 나타남 |
| | 14–30 | 점이 세로로 길어져 선 |
| | 32–50 | 선이 옆으로 벌어져 타원 |
| | 46–86 | 타원이 시계방향으로 돌며 두 개로 나뉨 (도는 양이 달라 벌어짐) → 2D 마크 |
| 다리 | 90–106 | 2D 링을 `HERO_MARK_POSE`로 보간 → 4프레임 크로스페이드로 3D 교체 |
| 2. 3D + 이름 | 102– | `startAt="mark"`, `speed=1.5`로 정지 상태에서 가속하며 회전 |
| | 130–160 | 3D 마크가 왼쪽 로크업 자리로 |
| | 136–162 | 워드마크가 한 번에 아래에서 48px 올라오며 투명 → 불투명 |
| 끝 | 214–240 | 3D가 한 바퀴를 마치고 마크 자세로 정지, 최종 로크업 |

이징: 1막 `cubic-bezier(0.83, 0, 0.17, 1)` (11번의 강한 가속·감속), 2막 `cubic-bezier(0.35, 0, 0, 1)` (Phi 인트로 이징)

## 의도에서 나온 결정
- **점 하나에서 시작합니다.** 가장 작은 기본 요소에서 출발해 "기본기"를 보여 줍니다.
- **요소를 하나로 줄였습니다.** 레퍼런스는 여러 요소(막대, 점, 배터리)가 함께 움직이지만, 여기서는 하나의 형태가 계속 모양을 바꿉니다. 하나의 생각이 자라는 느낌을 위해서입니다.
- **워드마크는 조용히 등장합니다.** 마크의 변화가 주인공이므로, 이름은 한 번에 올라오며 받쳐 줍니다.
