# 의도 카드

레퍼런스를 고른 직후, 프롬프트를 쓰기 전에 **5분 동안 손으로** 채웁니다. 프롬프트보다 이게 먼저입니다.

```text
[의도 카드]
1. 한 문장 의도: 이 인트로를 본 사람이 무엇을 느끼길 바라나?
2. 레퍼런스에서 가져올 원리 1가지 / 버릴 것 1가지:
3. 내가 더할 것 (레퍼런스에 없는 나만의 아이디어):
4. 왜 이게 Phi다운가 (Phi의 무엇과 연결되나):
5. 마지막 장면 (정지 화면을 말로 묘사):
```

```text
[_–_s]   ...

```
