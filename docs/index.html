/Phi Motion Study

Phi 로고로 8초짜리 인트로 영상을 만듭니다. 아래 7단계를 순서대로 따라 하면 됩니다. 오른쪽 위에서 내 컴퓨터(Windows / Mac)를 먼저 고르세요.

따라하기

스터디 전에 1~3단계, 스터디 때 4~7단계

  1. 1폴더 만들기
    1. 파일 탐색기를 엽니다. (단축키 ⊞ Win + E)
    2. 위쪽 주소창을 클릭하고 %USERPROFILE% 를 입력한 뒤 Enter. 내 사용자 폴더로 이동합니다.
    3. 빈 곳을 마우스 오른쪽 클릭 → 새로 만들기 → 폴더. 이름을 phi-motion-study 로 바꿉니다.
    1. Finder를 엽니다.
    2. 맨 위 메뉴에서 이동 → 홈 (단축키 ⇧ + ⌘ + H)
    3. 빈 곳을 오른쪽 클릭 → 새로운 폴더. 이름을 phi-motion-study 로 바꿉니다.

    바탕화면이나 OneDrive 안은 피하세요. 경로가 길거나 동기화되면 영상 만들기가 실패할 수 있습니다.

    사용자 폴더 안에 빈 phi-motion-study 폴더가 생겼다

  2. 2그 폴더에서 터미널 열기

    터미널은 글자로 명령을 내리는 창입니다. "폴더에서 연다"는 건, 터미널이 그 폴더를 보고 있는 상태로 연다는 뜻입니다. 그래야 다음 단계에서 소스가 이 폴더에 들어옵니다.

    1. 방금 만든 phi-motion-study 폴더를 더블클릭해서 들어갑니다.
    2. 위쪽 주소창을 클릭하고, 주소를 지운 뒤 powershell 을 입력하고 Enter.
    1. 터미널 앱을 엽니다. (⌘ + Space → "터미널" 입력 → Enter)
    2. 아래 명령을 복사해 붙여넣고 Enter. 터미널이 그 폴더로 이동합니다.
    cd ~/phi-motion-study

    창 맨 앞에 PS C:\Users\이름\phi-motion-study> 가 보인다

    줄 앞에 phi-motion-study 가 보인다

  3. 3설치 명령 붙여넣기

    아래 한 줄을 복사해서 터미널에 붙여넣고 Enter. (PowerShell에서는 마우스 오른쪽 클릭이 붙여넣기입니다.)(⌘ + V로 붙여넣기)

    irm https://raw.githubusercontent.com/yongzu/phi-motion-study/main/setup/setup.ps1 | iex
    curl -fsSL https://raw.githubusercontent.com/yongzu/phi-motion-study/main/setup/setup.sh | bash

    필요한 프로그램(Git, Node.js, Claude Code)을 설치하고, 소스를 이 폴더에 내려받고, 테스트까지 합니다. 이미 설치된 건 건너뜁니다. 5분 안팎.

    중간에 "이 앱이 변경하도록 허용하시겠어요?" 창이 뜨면 예를 누르세요.

    "Git 설치" 창이 뜨면 설치를 누르고, 끝나면 이 명령을 한 번 더 붙여넣으세요.

    준비 완료!가 나오고 폴더 창이 열리며 아래 파일이 보인다

    preview .cmd.command render .cmd.command references 폴더
  4. 4레퍼런스 고르고 넣기

    아래 레퍼런스 목록에서 하나를 고릅니다. 처음이라면 14번이나 03번.

    레퍼런스 탭 오른쪽의 레퍼런스 영상 받기로 ZIP을 받아 압축을 풀고, 영상 파일들을 폴더 안의 references 폴더에 넣습니다. 전부 넣어도 됩니다.

    references 안에 Reference_Video_14.mp4 같은 파일이 있다

  5. 5Claude 시작하기
    1. 3단계에서 쓰던 창에 아래를 입력하고 Enter. 창을 닫았다면 2단계처럼 폴더에서 다시 연 뒤 입력하세요.
    claude
    1. 처음이면 브라우저가 열립니다. Claude 계정으로 로그인하세요. (Pro·Max·Team 등 유료 요금제)
    2. 창에 /model 을 입력하고 Enter → Opus 5.5를 고릅니다.

    창 아래에 입력칸이 보이고, Opus 5.5가 선택되어 있다

  6. 6첫 메시지 보내기

    아래를 복사해서 [ ] 안을 내 말로 채운 뒤 Claude 창에 붙여넣습니다. 의도 카드는 5분 동안 먼저 생각해 보세요.

    CLAUDE.md 와 prompts/02-meta-prompt.md 의 순서대로 진행해줘. 레퍼런스: [번호]번 (prompts/references.md 의 [번호]번 설명 참고) 내 의도 카드 1. 한 문장 의도 (보는 사람이 무엇을 느끼길 바라나): [ ] 2. 레퍼런스에서 가져올 원리 / 버릴 것: [ ] 3. 내가 더할 것 (레퍼런스에 없는 내 아이디어): [ ] 4. 왜 이게 Phi다운가: [ ] 5. 마지막 장면 (멈춘 화면을 말로): [ ]

    Claude가 의도를 다시 말하고, 스토리보드 표를 먼저 보여줍니다. 괜찮으면 "좋아, 진행해", 아니면 고칠 점을 말하세요.

    Claude가 "MyIntro를 만들었다"고 알려준다

  7. 7보고, 고치고, 영상 만들기
    1. preview를 더블클릭 → 브라우저에서 왼쪽 목록의 MyIntro를 눌러 재생합니다. 이 창은 켜 두세요.
    2. 고칠 점을 Claude에 짧고 정확하게 말합니다. 고치면 미리보기에 바로 반영됩니다.
    3. 다 됐으면 render를 더블클릭 → 1분 뒤 out 폴더에 my-intro.mp4가 생깁니다.

    고칠 때는 이렇게 말하면 잘 통합니다.

    점 세 개는 필요 없고, 점 하나에서 시작해줘.

    글자는 하나씩이 아니라 한 번에 아래에서 위로 올라오게.

    헷갈리면: 스토리보드부터 다시 보여줘.

    my-intro.mp4를 공유 폴더에 내이름.mp4로 올렸다

레퍼런스

16개 · 영상의 "원리"만 가져오세요

레퍼런스 영상 받기 ZIP · 26MB

    예시

    11번 레퍼런스 · 명령이 바뀌면 결과가 바뀝니다

    1. 1의도를 담아 첫 결과

      11번 레퍼런스 비디오처럼 2d애니메이션이 끝난 뒤에, 지금 홈페이지에 있는 것처럼 3d로 돌아가면서 우측에 타이포로고가 등장하게 한다든지 하는. 이 내용을 합쳐서 프롬프트를 재작성해본다.

    2. 2빼고 바꾸기

      점 세개가 있을 필요가 없고, 점 하나에서 시작해서 점이 길어지며 라인이 된다. 라인이 타원형으로 바뀌고 이게 회전하면서 두개로 나뉜다. 타이포는 점으로부터 시작하는 것이 아니라 한번에 아래에서 위로 올라오게끔 한다. 투명했다가 불투명하게.

    3. 3먼저 묻고 비교하기

      카메라 무빙이나 줌 확대를 좀 고려해보고 싶다. 어떻게 적용할 수 있을지 채팅으로 가이드 응답한다.

      비교렌더한다.

    막혔을 때

    • 주소창에 powershell을 쳐도 안 열림시작 메뉴에서 PowerShell을 열고 cd ~\phi-motion-study 를 입력한 뒤 3단계로.
    • 설치가 중간에 멈춤창을 닫고 2단계부터 다시. 이미 된 부분은 건너뜁니다.
    • "스크립트를 실행할 수 없으므로" 오류예전에 다른 방법으로 설치한 Claude Code가 막힌 것입니다. 3단계 설치 명령을 한 번 더 붙여넣으면 고쳐집니다.
    • claude를 입력해도 없다고 나옴창을 닫고 2단계처럼 폴더에서 새로 연 뒤 다시 입력하세요.
    • 영상 만들기가 Chrome 오류로 실패폴더 경로가 깁니다. 폴더를 C:\Users\이름\ 바로 아래로 옮기세요.
    • 결과가 생각과 다름바로 고치지 말고 "스토리보드부터 다시 보여줘". 표에서 어긋난 줄을 짚어 고칩니다.
    • 시간이 부족함3D는 빼고 2D만 완성하세요.
    진행자용
    0–5분예시 영상, 오늘의 규칙 (소스는 그대로 · 원리만 가져오기 · 수정은 정확하게)
    5–20분라이브 데모: 11번 → 의도 카드 → 첫 메시지 → 스토리보드 → 결과 → 수정
    20–25분4단계: 레퍼런스 고르기, 의도 카드

    55–70분렌더 → 상영 → 한 줄 소감
